# akshare 上游对标 / 同步机制

为应对 akshare 持续变更,固定其对标版本(commit/版本号),将现有 akshare→本库映射表升级为**带锚点的对标表**(本库端点 ↔ akshare 函数名 ↔ akshare 源文件/行),并提供脚本/CI 任务:拉取 akshare 指定版本 → 解析 `registry.py` → 比对对标表 → 产出"新增/变更/移除"报告,提示同步。

**Why:** 用户明确要求"akshare 更新后我的代码也更新";抓取类库上游易变,需可审计的同步机制避免漂移。
**Trade-off:** 需维护对标表与同步脚本;文件/行锚点随 akshare 重构可能失效,需定期刷新。这是治理机制,非运行时功能。
