# 范围:最终对齐 akshare 全部对外接口,分期推进

最终目标实现 akshare 全部对外公开接口(以 `__init__.py` 重导出的 ~237 个编目名 / `registry.py` 目录为准,不含内部辅助函数),但采用垂直切片先行、横向扩展的分期策略。

第一阶段聚焦东方财富的 A股实时行情 + 指数,跑通"结构体 → 解析 → JSON/Parquet/CSV"全链路后,再覆盖其余领域与源。

**Why:** 用户定义"完全重构完"= 实现所有对外接口;但一次性全做不现实,需以可交付里程碑推进。
**Trade-off:** 全量含签名端点,故与 ADR-0005 协同——签名端点留到对应阶段逆向,不阻塞首版。
