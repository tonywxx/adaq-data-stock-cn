# Core Client 抽象与韧性策略

暴露可配置的 `Client`(持有 `reqwest::Client` + 超时/UA/并发配置)作为核心抽象,端点函数接收 `&Client`。`Client` 内建:指数退避重试(尊重 429 / `Retry-After`)、可选每源限流、全局并发信号量。另内建**可选**原始响应缓存层(默认关,可开;按 端点+参数 落盘本地),与转换层解耦。

**Why:** Rust 数据库以 Client handle 为惯例,配置与测试隔离清晰;上游反爬常返 429,内建重试+限流既保护上游也保护调用方;缓存省流量、支持离线。
**Trade-off:** 相比自由函数,调用方需持有/传递 Client;相比把重试限流全交调用方,内建增加 client 复杂度。默认关的缓存避免意外返回过期数据。
