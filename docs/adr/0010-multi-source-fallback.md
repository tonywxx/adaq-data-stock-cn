# 多源 fallback 机制

对每个逻辑数据端点,按优先级聚合多个源实现(如 A股实时行情的 eastmoney / sina / tencent),主源失败时自动降级到下一源,首个成功即返回。各源实现置于 `src/<domain>/<source>.rs`,逻辑端点函数(如 `stock::spot::realtime()`)依次尝试。fallback 后做字段/口径归一化,保证返回结构一致。

**Why:** 用户要求"更好确保能获取数据";抓取类库上游易挂/易变,多源互为备份显著提升可用性。
**Trade-off:** 不同源字段名/口径可能不同,需在 fallback 后归一化;源链增长带来维护成本。映射表记录每个逻辑端点的源优先级。与 ADR-0005(签名端点先绕开)协同:首版源链优先放无需签名的源。
